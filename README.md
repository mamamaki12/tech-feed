# Tech Feed

## 収集範囲と過去記事

通常のRSS/Atomに加え、Googleニュースの日本語セキュリティ検索RSSを収集します。リンクはGoogleニュースを経由する場合があります。記事の配信元は元媒体名を表示し、媒体ごとに除外できます。有料・会員限定の記事が含まれることがあり、無料全文の保証はしません。

RSSは最新の一部の記事しか返さないため、過去30日の記事をすべて網羅するものではありません。必要なテーマは `npm run collect -- --backfill "タイムズカー"` のように一度補充できます。補充した記事も通常の保存期間（30日）で管理します。同じURLや同一タイトルの重複を除き、直近30日・最大20,000件を保持します。

日本語のITニュースと技術記事をひとつの一覧で読む、登録不要のWebサイト。AI API・APIキー・サーバー契約は不要です。

## 機能

- RSS/Atomを複数の配信元から取得し、新着順に表示。URLの重複と追跡パラメータを除去
- 検索、分野のキーワード絞り込み、期間指定、既読非表示、あとで読む
- 「有料だった」で記事を非表示。希望すれば配信元も除外し、設定から復元
- 設定はlocalStorageに保存。端末間同期・会員登録なし
- 本文は転載せず、配信元へのリンクを表示。無料全文の自動判定は行いません

## ローカルで起動

Node.js 22以上で `npm ci` → `npm run collect` → `npm run serve`。 http://127.0.0.1:4173 を開きます。

## GitHub Pagesで公開

1. Settings → Pages → Build and deployment の Source を **Deploy from a branch** に設定
2. Branch は **main**、フォルダは **/docs** を選択して Save
3. 公開先は https://mamamaki12.github.io/tech-feed/

Actionsが有効なら約2時間おきにRSSを取得しJSONを更新します。実行時刻は遅延する場合があります。Actionsの「Collect articles」から手動更新も可能です。公開リポジトリでは長期間操作がないと定期実行が停止する場合があるためActions画面で確認してください。

`sources.json` に配信元を追加できます。取得結果は画面の「配信元・設定」に表示。失敗した配信元の前回記事は30日まで保持。日本語タイトルの記事を対象にしており、本文の言語まで判定するものではありません。分野は簡易的なキーワード判定です。

RSS公開は無制限の再利用許可を意味しません。公開運用時は配信元の利用条件に従い、停止依頼があった配信元は削除してください。
